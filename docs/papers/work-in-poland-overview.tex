\begin{abstract}
\noindent work-in-poland is a job board for Poland that an AI assistant can use directly:
searching jobs, comparing salaries, tracking applications and, for employers, posting jobs through
conversation. It is a deployable platform, not a proven market --- the analysis it follows
recommends validating demand with portals and employers before choosing between a niche board, an
MCP layer sold to existing boards, or a portfolio project, and none of that has happened yet.
\end{abstract}

\section{What it is, and what it refuses to be}

Listings are submitted by the employer. Applying is a redirect to the employer's own page: no CV is
stored or forwarded (\texttt{ADR 0004}), which keeps the system on the publishing side of the line
between publishing job ads and mediating employment. A listing cannot be published without a salary
range, and contract type and gross/net basis are separate fields (\texttt{ADR 0007}).

\section{Shape}

\begin{figure}[h]
\centering

One service owns the data (\repopath{WorkInPoland.Api}); the MCP server is an adapter inside it
(\texttt{ADR 0002}). Identity is \repopath{authservice}, run from its published image. The web app
is a Next.js backend-for-frontend: the browser talks only to its own origin.
