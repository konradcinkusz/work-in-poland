**API Contracts:**
- [x] `src/WorkInPoland.Contracts/Constants.cs`
  - Added operation names: `ReportJob`, `AdminListReports`, `AdminResolveReport`
  - Added vocabulary: `ReportReasons` (illegal, discrimination, scam, misleading, other)
  - Added vocabulary: `ReportStatuses` (open, actioned, dismissed)

- [x] `src/WorkInPoland.Contracts/Dtos.cs`
  - `JobReportRequest` — Request to report (reason, details, contactEmail)
  - `JobReportListItemDto` — Admin list item (includes jobTitle for readability)
  - `AdminReportQuery` — Query with status filter and pagination
  - `AdminResolveReportRequest` — Admin resolution (outcome, note)
  - Validation: Email format, enum values, max lengths

**Service Logic:**
- [x] `src/WorkInPoland.Api/Services/ReportingService.cs`
  - `CreateReportAsync(string jobSlug, JobReportRequest, CancellationToken)` — Anonymous reporting
    - Validates request
    - Finds job by slug or 404
    - Creates report with `status: open`
    - Logs report creation with jobId, slug, reason
  - `ListReportsAsync(AdminReportQuery, CancellationToken)` — Admin list
    - Filters by status if provided
    - Paginated (clamps to valid range)
    - Ordered by most recent first
    - Includes job title for context
  - `ResolveReportAsync(Guid reportId, string actor, AdminResolveReportRequest, CancellationToken)` — Admin resolution
    - Finds report or 404
    - Sets status (actioned/dismissed), ResolvedBy, ResolveNote, ResolvedAt
    - **Auto-unpublish logic:** If outcome is "actioned", finds the job and closes it
      - Sets `Status = "closed"`, `UnpublishReason = "Reported as {reason}"`
      - Logs auto-unpublish event
    - All admin actions logged with actor (sub)

**Dependency Injection:**
- [x] `src/WorkInPoland.Api/Infrastructure/ServiceCollectionExtensions.cs`

**Endpoints:**
- [x] `src/WorkInPoland.Api/Endpoints/PublicEndpoints.cs`
  - `POST /api/v1/jobs/{slug}/report` — Anonymous reporting
    - Input: `JobReportRequest` (validated)
    - Output: `202 Accepted` (fire-and-forget)

- [x] `src/WorkInPoland.Api/Endpoints/AdminEndpoints.cs`
